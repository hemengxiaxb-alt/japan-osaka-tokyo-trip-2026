这趟旅行的三个重要事件

必须安排

取戒指｜アイプリモ梅田ハービスENT店

建议：10/16（若14:00前落地）取货；10/17上午备用。地址：大阪府大阪市北区梅田2-2-22 ハービスプラザエント2F。营业 11:00–20:00，电话 06-6459-7281。距西梅田站很近。

出发前确认订单已完成、取货所需证件/订单号及是否需要预约；预留 1–2 小时，贵重物品不要放托运行李。

情侣放松

泡温泉｜空庭温泉 OSAKA BAY TOWER

建议：10/17 18:00–21:30。弁天町站直连，11:00–23:00（22:00 最后入场）。成人入馆约 人民币 ¥100–158/人（原价 ¥2,310–¥3,630），含毛巾和浴衣；两人约 人民币 ¥201–315。

公共浴池男女分开；想一起体验可另订私人浴池，约 人民币 ¥382 起/间/90 分钟（原价 ¥8,800 起），入馆费另计。出发前查 10 月票价日历及休馆日。

USJ优先建议

豪华版关西乐享周游券｜含日本环球影城

你说的这张券与 Osaka e-Pass PREMIUM 不同。当前产品说明显示：可在豪华套餐中兑换日本环球影城 1 日 Studio Pass，并按套餐规则再选择其他 Premium A/B/C/D 项目；激活后通常有连续 7 天使用窗口。

建议：10/18 用于 USJ。两人先在 Travel Contents App 绑定票券，确认 Premium A 里已选择 USJ Studio Pass，再看是否能搭配一个 Express Pass 指定项目、Power-Up Band/超级星星爆米花桶或其他权益。门票、Express Pass、爆米花桶不是同一件东西，不能默认全部包含。

购买前核对套餐是否为“含 USJ 一日票”版本、可选项目和预约库存；激活/兑换后通常不能改项目。预计价格以购买页为准，网站人民币金额只作参考。

不走回头路的每日路线

10/16
周五

抵达大阪｜先取戒指

  • 抵达关西机场后前往梅田，若航班在 14:00 前落地，争取当天前往アイプリモ梅田ハービスENT店。
  • 门店 11:00–20:00；从 KIX 到梅田需预留约 70–90 分钟，建议把“第一天取戒指”作为目标、10/17 上午作为备用。
  • 取戒指后入住梅田 / 难波酒店，晚上心斋桥、道顿堀简单逛街。
10/17
周六

大阪购物线｜空庭温泉

  • 若前一天航班延误，上午 11:00 前往梅田 I-PRIMO 取戒指。
  • 下午梅田、心斋桥、难波集中采购：奢侈品、中古店、服饰、帽子和眼镜。
  • 18:00 后前往弁天町空庭温泉，公共浴池男女分开；想一起泡请另订私人浴池。
10/18
周日

环球影城日｜使用豪华版关西乐享周游券

  • 早到 USJ，使用券内的 USJ 1 日 Studio Pass；出发前在 App 完成绑定、兑换和预约。
  • 如果套餐另含一个指定 Express Pass 项目，优先选超级任天堂世界 / 哈利波特相关需求最匹配的项目，具体以 App 可选库存为准。
  • USJ 一整天，不再安排大阪市区景点；交通需另付，除非你的套餐另含交通权益。
10/19
周一

大阪→东京｜浅草夜景

  • 新大阪乘东海道新干线到东京，约 2小时21分起；建议预留行李和进站时间。
  • 入住上野 / 浅草，下午浅草寺、仲见世、隅田川。
10/20
周二

东京经典线｜涩谷・银座

  • 明治神宫 → 原宿 → 涩谷十字路口与展望台。
  • 晚上银座 / 东京站购物，安排药妆、电器和伴手礼。
10/21
周三

东京返程

  • 上午在上野、东京站或机场免税店补购。
  • 东京出境优先比价成田 NRT / 羽田 HND→香港；如果深圳回程明显便宜，再比较东京→香港后陆路回深圳。

住宿与交通建议

大阪 3晚｜难波 / 心斋桥

方便 KIX 南海电铁、黑门市场和道顿堀；预算型双人房约 人民币 ¥300–400/晚（目标预算；东京可能需要上调）。若更重视取戒指和温泉，也可住梅田，减少 10/17 换乘。

东京 2晚｜上野 / 浅草

机场、浅草和购物动线平衡；预算型双人房约 人民币 ¥300–400/晚（目标预算；东京可能需要上调）。预订可免费取消的房型，等机票价格确定再锁定。

机票组合

首选开放式：香港→大阪 KIX，东京 NRT/HND→香港；同时比价深圳宝安→KIX / 东京→深圳。开放式票价若高于两张单程总价，就拆买两张单程。

购物清单与路线

奢侈品与中古｜心斋桥・难波

LV、Goyard（你写的“狗牙”若指 Goyard）、Chanel；建议逛御堂筋品牌店，再去 KOMEHYO、ALLU、Brand Off、RAGTAG、Kindal、2nd STREET 比价。中古包、首饰和钱包预算差异很大，建议预留人民币 ¥3,000–30,000+。

服饰与设计师品牌

三宅一生、川久保玲、Longchamp、优衣库、Montbell、The North Face、拉夫劳伦；可按心斋桥 / 梅田 / 涩谷银座分区购买。基础服饰约人民币 ¥100–2,000/件，设计师和奢侈品牌另行预算。

美妆与小物

机场买 Chanel 口红/护肤品；ELEGANCE“E大饼”、Canmake、电动睫毛夹、指甲刀。约人民币 ¥20–1,500/件，机场免税要留意液体和退税封袋。

帽子、包和鞋

CA4LA 帽子、防晒用品、SOU・SOU、Ball&Chain 布袋、Longchamp 双肩包、鬼塚虎芭蕾鞋和普通运动鞋；建议把鞋盒、包袋体积留到最后整理。

眼镜、户外与生活杂货

JINS / Zoff 配眼镜；MUJI 重点看收纳、旅行用品、文具和护肤；Lululemon 可以试穿后再决定，若一直没 get 到，不必为了购物清单硬买。

需要提前确认的品牌

Seika/菁华防脱洗发水请先确认准确日文品牌名和包装；SOU・SOU 在京都选择更集中，若不去京都可改为大阪百货或官方网店查货。

购物顺序：10/16 梅田取戒指后只逛轻便小物；10/17 集中买奢侈品、中古、服饰、眼镜和帽子；10/20 东京补买品牌与机场 Chanel。中古商品购买前检查成色、附件、保卡、维修记录和退税规则。

出发前要注意

  • 第一天取戒指必须以航班落地时间为前提：建议落地不晚于 14:00；同时保留 10/17 上午作为备用。
  • 豪华版关西乐享周游券需要绑定 Travel Contents App；购买前确认是“含 USJ 一日 Studio Pass”版本，且 USJ、Express Pass 和其他 Premium 项目分别是什么。
  • USJ 票券和部分项目需要预约，兑换后可能不能更改；10/18 不再安排大阪城、通天阁等市区景点。
  • 温泉公共浴池男女分开；纹身、饮酒后入浴等按现场规定执行。
  • 人民币金额按 1 日元≈0.0434 元人民币估算，实际汇率、票价、库存和酒店价格会变化。
